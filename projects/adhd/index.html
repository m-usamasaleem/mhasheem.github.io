Goal

Tutoring that fits how each child learns

The Bridge of Hopes builds AI assistive technology for children with ADHD and special needs. The aim is a system that recognizes how each child learns and tutors them accordingly, in their own language.

I set the research direction by studying where ADHD traits meet AI capabilities, so the system could identify how each child learns and tutor them accordingly.

Work

From no data to a working classifier

  1. Research direction

    Studied where ADHD traits meet AI capabilities to decide what the system should learn about each child.

  2. Urdu alphabet dataset

    Built a 6,220-image, 39-class dataset of Urdu letters, a resource with no public equivalent.

  3. Letter recognition

    Directed a CNN classifier that reached 95.52% accuracy (F1 = 0.96) on the dataset.
